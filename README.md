# República Adega

Site estático em português da República Adega, adaptado visualmente do portfólio `gabrielxcosta.github.io`.

## Publicação

1. Envie o conteúdo **desta pasta** para a raiz do repositório `gabrielxcosta/republica-adega`.
2. Em **Settings > Pages**, selecione **Deploy from a branch**, `main`, `/ (root)`.
3. Acesse `https://gabrielxcosta.github.io/republica-adega/` após a publicação.

## Estrutura

- `index.html` — Sobre
- `ex-alunos.html` — Ex-alunos
- `homenageados.html` — Homenageados
- `moradores.html` — Moradores
- `assets/site.css` — estilos
- `assets/site.js` — animação de entrada
- `imagens/` — emblema e imagem provisórios

## Personalização

- Substitua `imagens/emblema.svg` pelo emblema oficial (ou altere o caminho nos arquivos HTML).
- Substitua os cartões provisórios por pessoas reais **com autorização para publicar nome e fotografia**.
- Conteúdo histórico é provisório: não foram inventadas datas, nomes ou episódios.
- Cores em `assets/site.css`: marfim `#f8f3e7`, Vermelho Goya `#65292d`.

A estrutura tipográfica, navegação, classes e layout foram adaptados do repositório de referência. O conteúdo acadêmico, alternância de idioma e scripts específicos de pesquisa foram removidos por não serem pertinentes ao novo site.
